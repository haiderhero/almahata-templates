# قوالب المحطة للتقسيط

أداة على التلفون لمتجر «المحطة للتقسيط»: صورة من المعرض تصير ستوري أو بوست بتصميم المحل، صورة أو فيديو متحرك (7 ثواني)، وتنرسل لإنستغرام مباشرة.

**الرابط:** https://haiderhero.github.io/almahata-templates/

- 4 تصاميم (البيت، سينما، بطاقة، سريع)، كل واحد بمقاس ستوري 1080×1920 وبوست 1080×1350.
- بطاقة التواصل (نيلي أو برتقالي) بحواف شفافة.
- رقم المحل وحسابه والكلام فوقهم يتعدلون من ⚙ وينحفظون على التلفون.
- **«رتّب التصميم»:** كل شي بالتصميم (الشعار، السطر، الرقم والحساب، اسم المنتج، السعر، إطار الصورة) ينسحب لأي مكان ويكبر ويصغر بإصبعين أو بالشريط. الترتيب ينحفظ لكل تصميم ولكل مقاس، ويرجع للأصل بزر. والخطوط الحمرة تبيّن وين يغطي إنستغرام.
- بعد أول فتحة تشتغل بلا إنترنت، وتنضاف للشاشة الرئيسية مثل تطبيق.

## الملفات
- `scene.js`: التصاميم.
- `brand.js`: الشعار، مبني من جديد كرسم وخط Almarai، ويا حركته.
- `smoke.js`: الدخان.
- `export.js`: الحفظ (WebCodecs + mp4-muxer، ويا تسجيل احتياطي).
- `app.js`: المحرر.
